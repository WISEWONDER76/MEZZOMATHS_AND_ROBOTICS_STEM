Pedagogical Integration PAGE 04
Project 1: Obstacle Avoiding Robot

Project Design

An autonomous car with robotic eyes that scans its environment to stay safe and avoid crashing.

Firmware Logic

The code calculates how far away a wall is and guides the car's steering direction safely.

MEZZOMATHS Link

  • Doubling & Halving: Sound echoes forward and back! The robot measures total echo time and cuts it in half to calculate distance.
  • Speed & Distance: Uses multiplication to track how many centimeters sound travels per microsecond.
  • Greater/Less Than: If distance is less than 15cm, the robot triggers a quick pivot turn command.
Practical Implementations PAGE 05
Project 2: Smart Traffic Light System

System Mockup

A digital city intersection setup using coordinated LEDs and automated switching sequences.

Sequence Code

Runs a repeating pattern loop across three pins to turn lights on and off in order.

MEZZOMATHS Link

  • Division Remainders: Uses the remainder trick (Modulo) when dividing by 3 to create a perfect color loop (0, 1, 2) that resets back to 0 automatically.
  • Multiplication by 10: Instantly converts regular timeline seconds into milliseconds for the code timer.
  • Time Fractions: Sets ratio splits like 5/12ths of a cycle for Green and 2/12ths for Yellow.
Practical Implementations PAGE 06
Project 3: Smart Robotic Parking System

Grid Layout

A smart garage terminal that monitors real-time car entry gates and empty spaces.

Tracking Logic

Calculates total spaces, lifts up the gate barrier, and keeps track of cars entering.

MEZZOMATHS Link

  • Subtraction: Takes total parking lot spaces and subtracts active cars inside to find remaining empty spots.
  • Addition Counter: Adds +1 to the digital counter array each time a vehicle enters over the gate sensor.
  • Fraction Ratios: Calculates total capacity fraction scales (e.g., 4/5 full) to trigger warning light alerts.
Practical Implementations PAGE 07
Project 4: Smart Farm / Automatic Irrigation

Agro Infrastructure

A smart farm rig that reads moisture inside the dirt and activates a water pump relay.

Threshold Logic

Triggers water flow sequences when soil moisture readings drop below safety lines.

MEZZOMATHS Link

  • Percentages: Translates large, messy raw sensor values (0 to 1023) into clean, easy-to-read soil wetness percentages out of 100%.
  • Inequalities (≤): Uses the less-than-or-equal symbol to compare metrics. If wetness is ≤ 30%, the pump starts up.
  • Time Tracking: Uses exact multiplication to run pump timers, ensuring roots get just enough water.
Practical Implementations PAGE 08
Project 5: Smart Street Light System

Hardware Build

An energy-saving street light system that monitors ambient outdoor brightness using an LDR sensor.

Brightness Rules

Monitors the sky value, turns the high-power light output ON at sunset, and turns it OFF at dawn.

MEZZOMATHS Link

  • Finding the Average: Takes 3 separate light readings, adds them up, and divides by 3. This math average stops the light from flickering due to temporary shadows.
  • Less Than (<): Compares data to a fixed threshold. If average brightness level is < 400, the controller switches the lamp ON.
  • Data Ranges: Evaluates higher versus lower brightness scales to save electricity during daytime hours.
